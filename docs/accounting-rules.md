# 会計ルール（ゲーム内の会計モデル）

このファイルが計算の正です。実装は `src/engine/`、検証は `tests/accounting.test.ts` と `src/engine/checks.ts`。

## 1. 金額の単位と端数処理
- 内部の単位は「円」。金額は**すべて千円単位に四捨五入**する（`src/engine/money.ts` の `money()`）。負の数は絶対値で四捨五入。
- 四捨五入するのは「生まれた時点の金額」：週ごとの仕入れ代金、週ごとの商品別売上、ロットごとの原価配分、利息、減価償却費。
- 表示は**万円・小数1桁**に統一（例：`1,234.5万円`）。千円単位で計算しているため、表示上の合計も必ず一致する。
- マイナスは「−」記号と赤字で表示する（色だけに頼らない）。

## 2. PLの構造
```
売上高
− 売上原価（＝販売分の原価＋廃棄原価）
＝ 売上総利益（粗利）
− 販管費（＝人件費＋家賃＋広告費＋水道光熱費＋減価償却費）
＝ 営業利益（お店の本業でもうかった金額）
− 支払利息（むずかしいのみ）
＝ 経常利益（むずかしいのみ）
```
数値例：売上高 720万、販売分の原価 420万、廃棄原価 10万 → 売上原価 430万、粗利 290万。販管費 231万（人件費140・家賃50・広告10・光熱費16・減価償却5）→ 営業利益 59万。利息1万 → 経常利益 58万。

## 3. 1ターン（3か月＝13週）の中の計算 — 鮮度と在庫を矛盾させない方法
生鮮野菜を3か月そのまま持ち越せないように、**ターンの中を週単位で計算**する。

| 野菜 | 売れる期間（入荷から） | 冷蔵設備あり |
|---|---|---|
| トマト | 1週 | 2週 |
| キャベツ | 2週 | 3週 |
| にんじん | 4週 | 6週 |

毎週の流れ：
1. 週のはじめに「毎週の仕入れ数」が入荷し、1つの**ロット**（数量・原価・残り週数）になる
2. その週の需要 ＝ 予測需要 ÷ 13 ×（1＋期全体の予測誤差）×（1＋週ごとのばらつき）
3. 販売数 ＝ min(需要, 在庫) を、販売能力（人員 × 960個/週）で頭打ち（商品の需要に比例して配分）
4. **古いロットから売る**（先入れ先出し）
5. 週末に各ロットの残り週数を1減らし、0になった売れ残りは**廃棄**

期末に残っているのは「まだ売れる期間が残っているロット」だけで、これが期末在庫として次期へ持ち越される（トマトは売れる期間1週なので持ち越さない）。持ち越したロットの残り週数は次期にも引き継がれる。

## 4. 在庫の数量と金額
- 在庫は**原価で管理**する。ロットの金額 ＝ 千円単位に四捨五入した仕入れ代金。
- 期末にロットごとに原価を配分する：
  - 全部なくなったロット：廃棄原価 ＝ 原価 × 廃棄数 ÷ 入荷数（四捨五入）、販売分の原価 ＝ 残り
  - 残っているロット：期末在庫 ＝ 原価 × 残数 ÷ 入荷数（四捨五入）、販売分の原価 ＝ 残り
  - 端数は「販売分の原価」に寄せるので、ロットごとに **原価 ＝ 販売分＋廃棄分＋期末在庫** が必ず成り立つ
- 数量：**期首在庫＋当期仕入＝販売数＋廃棄数＋期末在庫**
- 金額：**期首在庫＋当期仕入＝販売分の原価＋廃棄原価＋期末在庫**

数値例（にんじん、原価45円）：期首在庫 0、毎週2,000個×13週＝26,000個（117.0万円）を仕入れ、販売25,000個、廃棄300個、期末在庫700個
→ 廃棄原価 1.4万円、期末在庫 3.2万円、販売分の原価 112.4万円（117.0−1.4−3.2）。

## 5. 仕入れと売上原価の違い
- **仕入れ（当期仕入）は費用ではない**。仕入れた時点では「在庫」というお店の財産（資産）が増えただけ。
- 費用（売上原価）になるのは、**売れたとき（販売分の原価）と捨てたとき（廃棄原価）**だけ。
- だから「売上原価 ≠ 仕入れ金額」。差は在庫の増減：売上原価 ＝ 期首在庫＋当期仕入−期末在庫。

## 6. 廃棄原価
- ゲーム上、廃棄原価は**売上原価に含め**、PLでは「うち 廃棄原価」として内訳を別に表示する。
- 販管費などほかの場所には入れない（**二重計上しない**）。テストで `売上原価＝販売分の原価＋廃棄原価` と在庫の式の両方を確認している。

## 7. 欠品・人手不足による機会損失
- 機会損失 ＝ 売り逃した数（欠品＋人手不足）×（販売価格−仕入れ値）。
- **参考指標**として表示するだけで、**PLの費用には入れない**（実際にお金が出ていったわけではないため）。

## 8. 費用の性質（固定費・変動費）— PLの区分とは別の切り口
PLの区分（売上原価・販管費）と、費用の性質（固定費・変動費）は**別の見方**であり、「販管費＝固定費」「売上原価＝変動費」とは一般化しない。このゲームの前提：

| 費目 | PLの区分 | 費用の性質（このゲームの前提） |
|---|---|---|
| 販売分の仕入原価 | 売上原価 | 変動費（売れた数量に比例） |
| 廃棄原価 | 売上原価 | 仕入れと売れ残りで変わる費用（売上に比例しない） |
| 人件費 | 販管費 | 固定費（期のはじめに決めた人数分。その期は売上に関係なくかかる） |
| 家賃 | 販管費 | 固定費 |
| 水道光熱費 | 販管費 | 固定費（毎期ほぼ一定とみなす簡略化） |
| 広告費 | 販管費 | プレイヤーが決める費用（売上に比例しない） |
| 減価償却費 | 販管費 | 固定費 |

### 損益分岐点（初心者向けの近似）
- 限界利益 ＝ 売上高 − 変動費（販売分の仕入原価）、限界利益率 ＝ 限界利益 ÷ 売上高
- **損益分岐点売上高 ＝（固定費＋広告費＋廃棄原価）÷ 限界利益率**
- 前提：価格・1個あたりの仕入原価の割合・人員・広告費・廃棄額が今期と同じ。広告費と廃棄原価は売上に比例しないので、固定費と同じ「売上で回収すべき費用」側に入れる。
- この定義なら **（売上高−損益分岐点売上高）× 限界利益率 ＝ 営業利益**（端数を除き一致。テストで確認）。
- 粗利率（粗利÷売上高）は廃棄原価を含むため、限界利益率とは別の指標として表示する。

数値例：売上高 720万、販売分の原価 464万 → 限界利益率 35.6%。固定費 221万＋広告費 10万＋廃棄原価 6万 ＝ 237万 → 損益分岐点 ≒ 666万。（720−666）× 35.6% ≒ 19万 ＝ 営業利益。

## 9. 設備投資と減価償却費（冷蔵設備・むずかしい）
| 項目 | 設定 | 根拠 |
|---|---|---|
| 投資額 | 100万円 | 小さな八百屋の業務用冷蔵ショーケース＋工事費を想定 |
| 耐用年数 | 5年（20四半期） | 法定耐用年数より短めの簡略化。ゲーム期間と同じ長さにして、償却の進み方を見やすくする |
| 減価償却費 | 5万円/四半期 | 定額法、残存価額0（100万÷20） |
| 維持費 | 電気代 +1万円/四半期 | 水道光熱費に加算 |
| 効果 | 売れる期間 トマト・キャベツ +1週、にんじん +2週 | 廃棄が減り、多めに仕入れても傷みにくい |

- **支出と費用は別**：代金100万円は買った期に全額現金で支払う（設備投資）。費用になるのは毎期の減価償却費5万円だけ。
- 1四半期の設備の費用は6万円（償却5＋電気代1）。**廃棄原価の削減などで6万円以上もうけが増えないと、営業利益では元が取れない**。
- 結果画面では、同じ乱数で「設備がなかった場合」を計算し、廃棄原価・粗利・設備の費用・営業利益への効果を表示する。
- シミュレーション（12シード平均）：予測どおりに仕入れるプレイでは効果はほぼゼロ〜小さなプラス、3割多く仕入れるプレイでは大きなプラス（`docs/progress.md` 参照）。
- 5年目終了時に残る設備の帳簿価額（未償却残高）は、**累計営業利益に加算しない**（費用になっていないだけで、もうけではない）。最終評価で別に表示する。

## 10. 借入と支払利息（むずかしい）
- 借入は100万円単位、上限500万円、年利4%。利息 ＝ その期の借入残高（借入・返済後）× 4% ÷ 4。
- **借入金の受け取りは売上ではない**（PLに載らず、手元資金だけが増える）。
- **元本の返済は費用ではない**（PLに載らず、手元資金だけが減る）。
- 支払利息は本業以外の費用なので、営業利益の下で引いて経常利益を出す。

## 11. 現金の出入り（初版は現金取引に簡略化）
| 時期 | 出入り |
|---|---|
| 期首 | ＋借入、−返済、−設備代金、−家賃 |
| 毎週 | −仕入れ代金（週のはじめ）、＋売上代金（その週のうちに現金で回収） |
| 期末 | −人件費、−水道光熱費、−広告費、−支払利息 |

- 売掛金・買掛金（ツケ）はない。
- 期中の手元資金を週ごとに計算し、**一度でもマイナスになれば資金ショート**（その期の判断か、1つ前の期からやり直せる）。

## 12. 利益と手元資金の関係
```
手元資金の増減 ＝ 営業利益
              ＋ 減価償却費（費用だが、お金は出ない）
              − 在庫の増加（お金が野菜に変わった。減少ならプラス）
              − 設備投資（買った期に全額支払い）
              ＋ 借入 − 返済
              − 支払利息
```
すべてのターンでこの式が成り立つことをテストで確認している（ランダムな判断で1,800ターン）。

## 13. 省略・簡略化しているもの
- 税金（法人税等）、消費税、特別損益、当期純利益
- 売掛金・買掛金（すべて現金取引）
- 店長自身の給与（人件費は雇った人員分のみ）
- 季節以外の需要の長期トレンド、物価上昇（むずかしいの人件費上昇・仕入れ値高騰のできごとを除く）
- 在庫の評価損、設備の売却、残存価額
これらは画面の「税金について」や遊び方で、省略していることを説明する。
