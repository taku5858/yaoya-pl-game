# ゲーム設計

## 目的と想定利用者
- タイトル：**八百屋さんで学ぶPL経営**
- 想定利用者：会計の初心者（大人）。簿記の知識は不要。
- 目的：八百屋の店長として5年間経営しながら、次のことを直感的に理解する
  - 売上が増えても、利益が増えるとは限らない
  - 売上高 → 売上原価 → 粗利 → 販管費 → 営業利益 のつながり
  - 値上げ・仕入れ・人員・広告などの判断がPLにどう効くか
  - 仕入れた金額すべてが、その期の売上原価になるわけではない
  - 利益と手元のお金は違う
- クリック連打や細かい店舗作業ではなく、**判断と振り返り**を楽しむ。1回15〜25分を想定（未計測）。

## 期間と1ターンの流れ
- 1ターン＝3か月（13週）、全20ターン＝5年。4月始まり（春→夏→秋→冬）。
- 各ターン：
  1. **状況を見る**：季節、できごと、仕入れ値、需要予測、持ち越し在庫、売れる期間、前期のPL
  2. **経営判断**：販売価格、毎週の仕入れ数量、人員、（広告費、冷蔵設備、借入・返済）
  3. **結果を予想**：「営業利益は増える？減る？」などを1問選ぶ
  4. **経営結果**：販売数・欠品・人手不足・廃棄・持ち越し、PL（前期比較）、手元資金
  5. **理由を学ぶ**：実際の数字で「なぜ利益が変わったか」を解説、在庫のつながり、利益と資金の違い、別の判断との比較
  6. **次の期へ**：ボタンを押すまで結果画面に留まり、落ち着いて確認できる

## 難易度
目標値は**仮の値**で、`npm run balance` のシミュレーションで調整する（設定は `src/config/gameConfig.ts`）。

| | イージー | ふつう | むずかしい |
|---|---|---|---|
| 累計営業利益の目標（調整後） | 1,500万円 | 1,700万円 | 1,500万円 |
| 開始時の手元資金 | 400万円 | 400万円 | 150万円 |
| 判断 | 価格・仕入れ・人員 | ＋広告 | ＋冷蔵設備・借入／返済 |
| 季節変動 | なし | あり | あり |
| 需要の誤差 | 期全体±2%、週±5% | 期全体±8%、週±12% | 同左 |
| できごと | なし | なし | 人件費上昇（予告あり）、仕入れ値高騰、競合の安売り、テレビで話題 |
| ヒント | 常に表示 | 任意 | 任意 |
| 予想PL（計算補助） | あり | なし | なし |
| 1ターン戻す | あり | なし（資金ショート時のみ） | 同左 |
| 学べる追加内容 | — | 広告の費用対効果、季節 | 減価償却、設備投資、支払利息、経常利益、資金繰り |

むずかしいの目標がふつうより低いのは、人件費上昇などの逆風があるため。そのかわりに資金繰り（借入・資金ショート）も評価する。難易度は乱数を増やすのではなく、判断項目と学ぶ内容を増やして上げている（需要の誤差はふつうと同じ）。

## 判断と影響（計算モデル）
| 判断 | 影響 | トレードオフ |
|---|---|---|
| 値上げ | 1個あたりの粗利↑、需要↓（標準より10%上げると需要が20〜25%減る直線モデル） | 上げすぎると販売数が大きく減り、利益も減る |
| 多めに仕入れ | 欠品↓ | 売れる期間を過ぎた売れ残りが廃棄に。在庫が増え資金が減る |
| 少なめに仕入れ | 廃棄↓ | 欠品による機会損失 |
| 人員を増やす | 販売できる上限↑（1人 週960個） | 人件費↑（1人 28万円/期、むずかしいは3年目から30万円） |
| 広告 | 需要↑（10万→+6%、20万→+10%、40万→+14%） | 費用↑。人手や在庫が足りないと効果が出ない |
| 冷蔵設備 | 売れる期間が延び、廃棄↓ | 100万円を一度に支払い、毎期 減価償却費5万＋電気代1万。廃棄が少ないと元が取れない |
| 借入 | 手元資金↑（売上ではない） | 利息（営業外の費用）。返済は費用ではない |

**「需要予測に合わせる」ボタン**：この価格・広告での予測需要（3か月分）から持ち越し在庫を引き、13週で割った数を「毎週の仕入れ数」に入れる。価格・人員・広告は変えない。需要予測は販売の保証ではなく、実際の販売数は価格・人員・在庫・予測誤差で変わることを画面で説明する。

単純な必勝法がないことは `npm run balance` で確認する（値上げし続ける・3割多く仕入れる・人と広告を最大にする は赤字）。

## 画面構成
- **タイトル**：難易度（目標・特徴）、乱数シード（任意）、つづきから、遊び方
- **メイン（判断）**：上部バー（年・季節・期、用語集、メニュー）、累計営業利益と目標、手元資金（＋借入残高・累計経常利益）、ターンの流れ①〜⑥、①状況、②判断、ヒント、予想PL（イージー）、前期のPLと前々期比較、「売上→粗利→営業利益」の流れ図、前期のポイント、営業利益の推移
- **予想**：問題、選択肢、前期の参考値、判断の確認
- **結果**：KPI、予想の答え合わせ、なぜ利益が変わったか（文と内訳バー）、気づき、PL（前期比較・流れ図）、販売の結果（週ごとの動き）、在庫のつながり、利益と手元資金、冷蔵設備の効果、費用の2つの見方と損益分岐点（3年目〜）、別の判断と比べる（同じ乱数）
- **資金ショート**：原因、この期／1つ前からやり直す
- **理解度テスト（5問）** → **最終評価**
- PC・スマートフォン両対応（900px以下で1カラム）。金額は万円・小数1桁、マイナスは「−」と赤字。

## クリア条件と評価
- 5年間（20ターン）を終えるとクリア。資金ショートは「やり直し」で、ゲームオーバーにはしない。
- **① 経営成績**（目標の達成率で S〜D）：累計営業利益、達成率、売上高、廃棄、売り逃し、赤字の期の数、手元資金。むずかしいは累計経常利益・借入残高・最低資金・資金繰りの評価も。設備の残りの価値は累計営業利益に含めず別表示。
- **② PL理解度**（100点で S〜D）：途中の予想問題20問（50点）＋最後の理解度テスト5問（50点）。分野別に「理解できていること」「復習するとよいこと」を表示。
- 目標に届かなくても、理解度は別に評価して示す。
- 「あなたの判断がPLをどう変えたか」を、実際の期の数字で振り返る。
