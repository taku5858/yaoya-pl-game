# 学習設計

実装：`src/learning/`（用語集・解説・問題）。外部AI APIは使わず、**計算済みの数値と説明テンプレート**で文章を作る。解説の数字はすべて `TurnResult` から取り、PLの表示と一致させる（`tests/learning.test.ts` と `npm run e2e` で確認）。

## 段階的に解放する内容
| 年 | テーマ | 解放されるもの |
|---|---|---|
| 1年目 | 売上・原価・粗利 | 売上高、売上原価（販売分・廃棄分）、粗利、在庫、売れる期間、廃棄原価、機会損失、手元資金、需要予測。営業利益は目標なので最初から表示し「お店の本業でもうかった金額」と添える。販管費は「経費（家賃・人件費など）」とまとめて表示 |
| 2年目 | 販管費・営業利益 | 販管費とその内訳、（むずかしい）支払利息・経常利益 |
| 3年目 | 粗利率・固定費・変動費 | 粗利率、費用の2つの見方（PLの区分と費用の性質は別の切り口）、変動費、固定費 |
| 4年目 | 損益分岐点 | 限界利益率、損益分岐点（近似であることと前提を表示） |
| 5年目 | 総合判断 | 利益と資金の関係を問う予想問題 |

- 減価償却費（むずかしい）は冷蔵設備を買える1年目から解放する。
- 各年の最初の期に「今年のテーマ」カードを出す。
- 用語を押すと、一言の説明と「今回の数字では」の例を表示する（例：「売上高 720.5万円 − 売上原価 470.0万円 ＝ 粗利 250.5万円」）。
- 未解放の用語は用語集で 🔒 と「○年目で解放」と表示する。

## 各ターンの予想問題
結果を見る前に1問答える。答えは結果の数字から決まり、解説も結果の数字で作る。

| 年 | 問題（期ごとに入れ替え） |
|---|---|
| 1年目 | 仕入れた金額は全部売上原価になる？／売上高は増える？／粗利は増える？／廃棄は1,000個を超える？ |
| 2年目 | 営業利益は増える？／販管費は増える？ |
| 3年目 | 粗利率は上がる？／売上が1割減っても家賃と人件費は同じ？ |
| 4年目 | 売上高は損益分岐点を上回る？ |
| 5年目 | 手元資金の増え方は営業利益より大きい？ |

最初の期など前期がない場合は「営業利益は黒字になる？」に置き換える。イージーでは予想PL（計算補助）を見ながら答えられる。

## 実際の数字に基づく振り返り
- **なぜ利益が変わったか**：前期との差を項目別（売上高、販売分の原価、廃棄原価、人件費、広告費、水道光熱費、家賃、減価償却費）に分解し、合計が営業利益の差と一致することを保証する。文例：「売上は前期より 13.2万円 増えましたが、人件費が 84.0万円 増えたうえ、販売分の原価が 11.7万円 増えたため、営業利益は 92.9万円 減りました。ほかに 廃棄原価 +10.4万円 も動いています。」
- **気づき**：欠品（機会損失）、廃棄と売れる期間、値上げ・値下げの効果、人手不足・人員過剰、広告、できごと、冷蔵設備の効果（同じ乱数で設備なしと比較）
- **在庫のつながり**：期首在庫＋当期仕入＝販売分の原価＋廃棄原価＋期末在庫 を図で示す
- **利益と手元資金**：営業利益から資金の増減までの差を項目別に示し、期中の最低資金も表示
- **費用の2つの見方**（3年目〜）：費目ごとにPLの区分と費用の性質を並べた表
- **別の判断と比べる**：同じ乱数で別の判断を計算し、PL・販売数・廃棄・資金の差と理由を表示
- **最終振り返り**：最も利益が出た期／少なかった期、売上が増えたのに利益が減った期、廃棄が多かった期、価格・人員を変えた判断、冷蔵設備（支払額・償却済み額・残りの価値・効果の合計）、利益とお金

## 最後の理解度テスト（5問）
1. 売上高が増えれば営業利益も必ず増える？（あなたの実例があれば使う）
2. 粗利の求め方（売上高−売上原価）
3. あなたの期の数字で：期首在庫・仕入れ・期末在庫から売上原価を求める
4. 利益が出ているのに資金が増えない理由（在庫の増加など）
5. あなたの最終期の数字で：損益分岐点売上高（近似）を求める

回答ごとに正誤と解説を表示する。

## 初心者が誤解しやすい点と、ゲームでの扱い
| 誤解 | ゲームでの扱い |
|---|---|
| 仕入れた金額＝その期の費用 | 予想問題1問目、在庫のつながり図、毎期の「仕入れと売上原価」の文 |
| 売上が増えれば利益も増える | 前期比の分解と「売上は増えましたが…」の文、最終テスト1問目 |
| 利益が出ていればお金も増える | 利益→資金の表、5年目の予想問題、最終テスト4問目 |
| 販管費は固定費、売上原価は変動費 | 「費用の2つの見方」で別の切り口として説明。人件費は販管費かつ固定費、廃棄原価は売上原価だが売上に比例しない、など |
| 捨てた野菜はPLに出てこない | 廃棄原価を売上原価の内訳として表示 |
| 売り逃しも損失として費用になる | 機会損失は参考値でPLに入らないと明示 |
| 借りたお金は収入、返済は費用 | 借入・返済の欄の説明と、利益→資金の表 |
| 設備を買った期に全額費用になる | 減価償却の説明、設備の効果表、最終振り返り |
| 需要予測どおりに売れる | 「需要予測に合わせる」ボタンの説明、販売結果の「予測」と「実際の需要」の併記、週ごとの動き |
